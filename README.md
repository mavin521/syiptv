## 自动更新

每天自动更新！

更新脚本会从公开来源聚合频道、按名称关键词分类、去重，并对频道地址做 HTTP 可访问性检查。HTTP 检查成功不代表流一定能播放；频道分类和可用性会随上游源变化。
